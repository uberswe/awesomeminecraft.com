# MCToolLab Skin Editor

**Website:** [https://mctoollab.com/skin](https://mctoollab.com/skin)

**Category:** Player Customization > Skin Editors

---

## Overview

Free browser-based 64 × 64 skin editor with 2D painting, a Classic/Slim 3D preview, optional skin-part combining, and PNG export. Legacy 64 × 32 skins can be normalized; HD skins and direct 3D painting are not supported.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Java & Bedrock (standard skin PNG) |
| **Audience** | Casual |
| **Price** | Free |
