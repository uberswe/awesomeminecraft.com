# Block Skin Maker

**Website:** [https://blockskinmaker.com/](https://blockskinmaker.com/)

**Category:** Player Customization > Skin Editors

---

## Overview

Browser-based 2D pixel editor for skin PNGs, with mapped Body and Overlay passes, mirrored strokes, undo/redo, and PNG export. Files are processed locally in the browser; no account is required.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web browser; exported texture compatibility depends on the target game or mod |
| **Audience** | Skin creators |
| **Price** | Free |
