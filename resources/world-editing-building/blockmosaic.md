# BlockMosaic

**Website:** [https://mcimagetool.com](https://mcimagetool.com)

**Category:** World Editing & Building > Schematic Tools

---

## Overview

Browser-based tool that converts any image into Minecraft block pixel art or map art. Generates a block shopping list and exports the build as a `.litematic` (Litematica) or `.schem` (WorldEdit/Sponge) schematic.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web |
| **Audience** | All |
| **Price** | Free |

## Features

- Converts images to Minecraft block palettes (full block palette or official map-color palette)
- Generates exact block shopping lists with stack counts
- Exports `.litematic` and `.schem` schematics for direct in-game building
- Runs entirely client-side — images never leave the browser
