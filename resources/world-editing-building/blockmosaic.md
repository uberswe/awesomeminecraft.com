# BlockMosaic

**Website:** [https://mcimagetool.com](https://mcimagetool.com)

**Category:** World Editing & Building > Schematic Tools

---

## Overview

Browser-based tool that converts any image into Minecraft blocks and exports it as a schematic (.litematic for Litematica, .schem for WorldEdit, or .mcfunction commands). Also includes a Litematica-to-Schematic file converter, a block shopping list, and a map-art mode.
