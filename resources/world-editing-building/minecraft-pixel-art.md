# Minecraft Pixel Art

**Website:** [https://minecraft-pixel-art.com/](https://minecraft-pixel-art.com/)

**Category:** World Editing & Building > Building Planners

---

## Overview

Free browser workbench for turning images into Minecraft block blueprints, editing block art, planning materials, and following the build layer by layer.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web |
| **Audience** | Java and Bedrock creators |
| **Price** | Free |

## Features

- Converts images into block-by-block blueprints
- Supports manual editing and practical palette planning
- Provides block counts and material shopping guidance
- Exports NBT and PNG outputs
- Shares build plans to a phone with QR viewing
