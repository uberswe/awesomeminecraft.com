# Minecraft Pixel Art Converter

**Website:** [https://mcimgart.com/](https://mcimgart.com/)

**Category:** World Editing & Building > Building Planners

---

## Overview

Free browser tool that converts an uploaded image into a Minecraft block-art plan. Players can choose a block palette, preview the result, and export files for building the design in-game.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web |
| **Audience** | All |
| **Price** | Free |

## Features

- Converts uploaded images into block-based pixel art
- Lets players choose and adjust the block palette
- Provides a block-by-block build preview
- Supports different output dimensions
- Exports schematic and mcfunction files
- Runs directly in a web browser
