## Overview

Minecraft Java instance manager with DNA links for sharing exact modpack versions and selected configs.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Java |
| **Audience** | Players and modpack authors |
| **Price** | Free with optional Premium |
| **Operating systems** | Windows x64 and Linux x64 |

DNA links record versions of mods, resource packs and shaders, together with selected configs and instance settings. Creating and importing these links is free. The launcher also includes a Modrinth catalogue and an optional AI assistant in alpha for finding mods and analysing logs.

[Downloads](https://launcher.ctf.mom/). Minecraft Java Edition is purchased separately. The launcher is closed-source.
