# MCSift Nether Portal Calculator

**Website:** [https://mcsift.com/tools/portal-calculator/](https://mcsift.com/tools/portal-calculator/)

**Category:** Calculators & Tools > Universal Tools

---

## Overview

A free browser calculator for converting X and Z coordinates between Minecraft's Overworld and Nether at the default 8:1 scale. It supports both travel directions and keeps negative coordinates signed.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web |
| **Audience** | Minecraft players planning Nether travel |
| **Price** | Free |

## Features

- Choose Overworld to Nether or Nether to Overworld conversion
- Enter signed X and Z coordinates and copy the result
- See the calculation rule when JavaScript is unavailable
- Read practical notes about height, terrain, and nearby portal links
- Clearly states that Nether math does not apply to The Sift or custom dimension scales

The calculator does not read a world save or guarantee which existing portal the game will select.
