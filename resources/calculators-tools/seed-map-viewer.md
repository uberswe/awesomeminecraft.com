# Seed Map Viewer

**Website:** [https://seedmapviewer.com/](https://seedmapviewer.com/)

## Overview

Free in-browser Minecraft seed map and seed/village/biome/stronghold finders (Cubiomes engine, Java + Bedrock, no signup).

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web |
| **Audience** | All |
| **Price** | Free |

## Features

- Full biome map rendered in the browser from any seed (Cubiomes engine, WebAssembly)
- Seed, village and biome finders across 14 structure types
- Stronghold Finder listing all 128 strongholds in a seed, nearest first
- One-click copyable /tp commands for strongholds
- Java (up to 26.3) and Bedrock support
- Free with no signup and nothing to download

## Versions

- **Java Edition:** Up to 26.3
- **Bedrock Edition:** Supported
