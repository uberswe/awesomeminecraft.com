# Minecraft Enchantment Calculator

**Website:** [https://enchantmentcalculator.online/](https://enchantmentcalculator.online/)

**Category:** Calculators & Tools > Universal Tools

---

## Overview

A free browser tool for planning enchantments in vanilla Minecraft Java Edition 26.3. Check the chances of specific enchantments or complete combinations before spending experience levels and lapis. Plan the order of anvil merges when you already have the gear and books.

## Details

| Property | Value |
|----------|-------|
| **Platform** | Web |
| **Audience** | Minecraft Java Edition players |
| **Price** | Free, no account required |

## Features

- Set the item, effective bookshelf count, and enchanting slot.
- See exact enchantment probabilities across the complete 32-bit player XP seed space.
- Plan an anvil order for one piece of gear and up to nine fresh single-enchantment books.
- Account for the gear's existing enchantments and prior work penalty.
